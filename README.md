# Kviskre

Norwegian dictation for Mac: hold a key, speak, release, and the text lands in whatever app you are using.
Powered by NB-Whisper from the National Library of Norway. Everything runs on your Mac; nothing leaves your computer.

**[Download the latest version for Mac](https://github.com/kjeva/kviskre/releases/latest/download/Kviskre-arm64.dmg)**
(Apple Silicon, macOS 14 or newer)

All versions and release notes: [Releases](https://github.com/kjeva/kviskre/releases).
Verify a download with `shasum -a 256 -c Kviskre-arm64.dmg.sha256`.

Questions or problems: open an [issue](https://github.com/kjeva/kviskre/issues).
